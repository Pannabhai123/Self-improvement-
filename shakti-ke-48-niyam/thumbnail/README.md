# थंबनेल (YouTube cover)

| फाइल | क्या है |
|---|---|
| **`youtube-thumbnail.jpg`** | **फाइनल थंबनेल — 1280×720, 259 KB** (YouTube की 2 MB लिमिट से अंदर) |
| `youtube-thumbnail.png` | वही, बिना कम्प्रेशन (एडिट करना हो तो यही इस्तेमाल करो) |
| `cover.png` | बिना टेक्स्ट वाला बेस इमेज (दूसरे टाइटल/टेक्स्ट के लिए) |
| `make_thumbnail.py` | जेनरेटर — टेक्स्ट बदलना हो तो इसमें एडिट करके `python3 make_thumbnail.py` चलाओ |
| `NotoSansDevanagari.ttf` | हिंदी फॉन्ट (शेपिंग के लिए uharfbuzz + freetype-py) |

## डिज़ाइन में क्या है
- **बाईं तरफ़:** चेहरा, आधा रोशनी में आधा अंधेरे में — आँख से आँख मिलाते हुए (CTR के लिए सबसे ज़रूरी)
- **दाईं तरफ़:** सुनहरा ताज + तलवार, चिंगारियाँ
- **टेक्स्ट:** "शक्ति के" (सफ़ेद) + "**48 नियम**" (सुनहरा, काला आउटलाइन)
- **बैज:** लाल पट्टी में "पूरी किताब · 1 घंटे में"

## टेक्स्ट बदलना हो तो
`make_thumbnail.py` में सिर्फ़ ये 3 लाइनें बदलो:

```python
t1 = fit("शक्ति के", 68, 460, color=WHITE, stroke=6)
t2 = fit("48 नियम", 168, 590, color=GOLD, stroke=10)
badge = render_text("पूरी किताब · 1 घंटे में", 40, (255, 245, 235), stroke=5)
```

`fit()` वगैरह खुद साइज़ छोटा कर देगा ताकि फ्रेम से बाहर न निकले।
