## इस्तेमाल हुए इफ़ेक्ट

- केन बर्न्स ज़ूम — बारी-बारी से अंदर (1 → 1.12) और बाहर (1.12 → 1)
- कलर ग्रेड: contrast 1.07, saturation 1.10, थोड़ा डार्क
- विनेट (किनारे गहरे) + फ़िल्म ग्रेन
- हर नियम के बदलाव पर 0.35 सेकंड का क्रॉसफ़ेड
- कार्ड फेड-इन / फेड-आउट, नीचे गोल्ड बॉर्डर वाली लाइन
- आख़िर में फेड-आउट, `+faststart` (YouTube पर तुरंत चलता है)

## दोबारा बनाना हो तो

```bash
cd shakti-ke-48-niyam/video
python3 build_video.py        # ~16 मिनट, 8-कोर पर
```

ज़रूरी चीज़ें:
- `../audio/pura-voiceover.mp3` (आवाज़, 1:00:03) और `../audio/clip_times.json` (टाइमिंग)
- `../thumbnail/cover.png` (बैकग्राउंड) और `../thumbnail/youtube-thumbnail.jpg` (शुरुआती कवर)
- `pip install --break-system-packages imageio-ffmpeg uharfbuzz freetype-py pillow numpy`
- ffmpeg अलग से नहीं चाहिए — `imageio_ffmpeg` अपना ffmpeg ले आता है

फ़ाइलें:
- `build_video.py` — पूरा बिल्डर (कार्ड बनाना, सेक्शन रेंडर, जोड़ना, आवाज़ मिलाना)
- `textrender.py` — हिंदी टेक्स्ट रेंडरर (HarfBuzz शेपिंग + FreeType, ताकि मात्राएँ सही जुड़ें)
- `NotoSansDevanagari.ttf` — फ़ॉन्ट
- `cards/` — हर नियम का कार्ड (PNG, पारदर्शी बैकग्राउंड)

> नोट: `.mp4` फ़ाइल गिट में कमिट नहीं की गई (साइज़ बहुत बड़ा है)। स्क्रिप्ट और कार्ड कमिट हैं, इसलिए वीडियो कभी भी दोबारा बन सकता है।
